# Учёт успеваемости

Учебный проект к лабораторной работе №2 по курсу
«Технологии разработки программного обеспечения».

Запуск программы: python main.py
Требуется Python версии 3.8 и выше.

## Возможности

- расчёт среднего балла студента;
- проверка аттестации студента;
- вывод названий оценок.

## Выгрузка в CSV

После запуска результаты сохраняются в файл results.csv
(разделитель — точка с запятой).

## Статистика

Модуль stats.py вычисляет медиану оценок студента.
